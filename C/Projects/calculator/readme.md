# Simple Calculator

A simple command-line calculator written in **C** to reinforce fundamental programming concepts and practice implementing basic operations.

## What I Practiced

* **Variables** 
* **Functions** 
* **Conditional Statements** 
* **User Input** 
* **Operators** —
* **Basic Error Handling** 

## Supported Operations

| Operator  | Operation      |
| --------- | -------------- |
| `+`       | Addition       |
| `-`       | Subtraction    |
| `*` / `x` | Multiplication |
| `/`       | Division       |

## Example

```text
enter first num : 10
enter operation : *
enter second num : 5
result : 50
```

## Purpose

This project is part of my **C programming fundamentals** and is intended to reinforce basic programming concepts through a small, practical application.
