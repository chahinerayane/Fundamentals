# Number Base Converter

A simple C program created to practice fundamental programming concepts while working with number systems.

## Features

- Accepts a number from the user.
- Supports binary (`base 2`) and decimal (`base 10`) input modes.
- Calculates the decimal value using positional notation.
- Displays a message for unsupported base types.

## How to Run

**0. You will nead a compiler in case of gcc**

**1. Compile the program**

```bash
gcc main.c -o converter
```

**2. Run it**

```bash
./converter
```
